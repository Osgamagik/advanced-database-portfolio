# Individual Technical Reflection

I chose a healthcare clinic as my case study because of the way clinics and the wider healthcare system are structured and organised. My environment and locale were a major factor. Seeing the constant errors and delays within the Nigerian healthcare system was a big influence, and also a source of inspiration. My daily interaction with people through my outreach work also played a key part in this choice.

The part of the project that surprised and challenged me most was report speed, and how data from different departments has to be brought together in the database to produce those reports.

The hardest part was choosing the right system and type of database for this project. It was also a very different experience for me, because I had never worked with a GitHub repository or built a portfolio like this before. The whole process was quite an adventure.

For a network of 50 clinics, I would use a better database structure.
